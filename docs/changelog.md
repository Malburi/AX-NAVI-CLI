# AX Navi 변경 이력

> 이 문서는 AX Navi(`ax-navi`, 옛 `total-ito`·`ax-std-harness`) 플러그인 저장소 자체의 세션별 개발 변경 기록이다. harness-init이 대상 프로젝트를 분석·생성할 때는 전혀 읽지 않는다 — 순수하게 이 저장소를 세션 넘어 개발할 때 과거 결정을 참고하기 위한 다이어리다. 2026-09-10에 행별 요약으로 압축했다. 압축 전 상세 원문은 git 이력의 `be06c60` 커밋 이전 `docs/changelog.md`를 참조한다.
